# DripGuard Testing Programs

This directory contains individual programs used to test the hardware components and monitoring functions of the DripGuard system.

| Filename | Purpose |
|---|---|
| `test_01_drop_sensor.ino` | Tests drop sensor detection. |
| `test_02_status_leds.ino` | Tests status LED operation. |
| `test_03_buzzer.ino` | Tests buzzer operation. |
| `test_04_drop_counting.ino` | Tests drop counting. |
| `test_05_flow_volume_time_calculation.ino` | Tests flow rate, volume, and time calculations. |
